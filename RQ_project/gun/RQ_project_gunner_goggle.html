部屋モード: キャリブレーション待ち
床のグリッドが実際の床にピタッと重なるように合わせる（目地・壁の際が目安） 開始後、床を照準で指して「📍 ボスを置く」でその場所に立たせます（位置は保存）。 目安：ゴーグルのレンズの中心間隔（多くは約6.3cm）÷ スマホを横にした時の画面の横幅。例: 画面幅15cm → 42%。映像が近すぎる・二重に見える時は小さく。 横向きでゴーグルに入れ、PCのメインカメラの方を向いて Wii の − で向きを合わせる。B でスタート。
PC側で calibrate_2cam.html のキャリブレーションが済んでいれば「部屋モード」になり、ボスが床の決まった位置に立って周りを歩けます。
USBカメラは接続後「一覧を更新」

MENU

🔫 ガンナー設定 十字で武器切替: ↑=ハンドガン(8発) / ←=P90(50発・押しっぱなしで連射) / →=スナイパー(1発ずつ) / ↓=ビームサーベル
スナイパー: 伸び縮みする白い円が金色の帯の中に入った時（緑に光る間）に撃つと命中
サーベル: 前に突く=突き / 縦・横に大きく振る=重撃（B=突き）。MotionPlus付きなら剣士版と同じジャイロ判定
Wii: B=射撃・攻撃 / A長押し=ガード / 振り上げ=パリィ（ボタンは押しても押さなくてもOK）/ 縦に立てる=リロード（黄色の所でB）
1=グレネード / 2=時限地雷 / +=回り込み弾 / −=照準を中央に（画面中央に向けて押す）/ HOME=メニュー
マウス: ←↑→↓ か 1〜4=武器切替 / サーベルはクリック=突き・ドラッグ縦横=重撃（W/Sでも可）/ G=グレネード F=地雷 Q,E=回り込み
照準が四角に重なると赤くなり、その時だけ当たります
黄色い小さい四角=弱点（回避直後・スタン中だけ開く）
✋ 人差し指で「1」を描く / M キーで開閉
🔇 音を出すには、画面を一度クリック（またはキーを押す）してください
