ABOUT

赤は弾け。紫は受け止めろ。

ボスは「ジャイアントスライム」ただ一体。突進の予兆を見極めて、パリィ・ガード・回避を使い分けるシンプルで手応えのあるボス戦です。Webカメラで顔の向きを読み取って照準を動かしたり、Wiiリモコンを実際に振って斬ったりと、体を使って遊べるのが最大の特徴です。

🗡️

一人称の大剣アクション

視界の右下には自分の大剣。斬撃のエフェクト、ヒットストップ、画面の揺れで「当てた」手応えをしっかり返します。

👤

顔の動きで照準

Webカメラが顔の向きを認識し、そのまま視点と狙いに反映。マウスに持ち替えなくても、首を振るだけで狙えます。

🎮

Wiiリモコンで本当に振る

Bluetooth接続したWiiリモコンをブラウザから直接認識。縦に振る、突く、一回転…動きに応じてソードスキルが発動します。

BOSS

ジャイアントスライム

攻撃はシンプルな突進。ただし、光る色で対処法が変わります。床に伸びる帯は突進のコース。色を見て、一瞬で判断しましょう。

赤く光る突進 → パリィ

光っている間に右クリック（パリィ）すると弾き返してスタン。直後の一撃が大ダメージの COUNTER に。ぶつかる直前ギリギリで弾くと PERFECT 判定になり、スタンもダメージも大きくなります。

紫に光る突進 → ガード

「パリィ不可！」の合図。パリィすると被弾するので、長押しガードで受け止めます。ガードは赤い突進にも有効です。

突進のあと → 弱点

突進を空振りさせたあとの短い時間は、通常攻撃のダメージがアップします。

SWORD SKILLS

振り方で技が変わる

Wiiリモコン（MotionPlus 推奨）の動きを読み取って、ソードスキルが発動します。ボスへ自動で命中し、通常攻撃よりはるかに大きなダメージを与えます。反応しにくい時はメニューから「自分の振り」を登録して判定を調整できます。

INPUT & MODES

いろんな遊び方ができる

マウスだけでも最後まで遊べます。手持ちの機材に合わせて、好きなものを組み合わせてください。

🖱️

マウス＆キーボード

いちばん手軽な標準操作。カメラなしでもOK。

👤

顔トラッキング

Webカメラで顔の向きを認識し、視点と照準を操作。感度や中心位置も調整できます。

✌️

ハンドジェスチャー

ピースサインでメニューを開き、指先でカーソル操作。コントローラーを置かずに設定を変えられます。

🎮

Wiiリモコン＋ヌンチャク

WebHIDで直接接続。MotionPlusのジャイロでソードスキル、ヌンチャクで二刀流。振動フィードバックつき。

🧍

俯瞰モード（VRM）

好きなVRMアバターを読み込み、全身の動きをカメラで反映。体を左右に動かして回避する、体を使ったモードです。

📷

AR風の背景

2台目のカメラ映像や手持ちの動画・画像をボスの背景に。自分の部屋にスライムが現れます。

そのほかの機能

VR（左右分割）表示、負荷モード切替（高画質 / 標準 / 軽量）、効果音・BGM の音量調整、Wii振り感度調整、ジョブチェンジ。

GET STARTED

はじめかた

  1. PC版の Chrome か Edge でゲームを開くWiiリモコンの接続（WebHID）は Chrome / Edge のみ対応です。
  2. ノートPCなら右上「📷 カメラ設定」で「軽量」モードを選ぶ初期設定は軽量モードです。動作が重いときは確認してください。
  3. 画面をクリックしてスタートカメラの使用許可を求められたら「許可」。顔認識を使わない場合はマウスで操作できます。
  4. （任意）Wiiリモコンを接続PCとBluetoothでペアリングしてから、画面の「🖱 マウス」ボタンで操作方法を切り替えます。
