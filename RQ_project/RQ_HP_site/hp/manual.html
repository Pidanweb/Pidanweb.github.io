01

動作環境

PCのブラウザで動きます。スマートフォン・タブレットでの動作は想定していません。

BROWSER
Google Chrome ／ Microsoft Edge（最新版）Wiiリモコン接続（WebHID）と音声認識がこの2つでしか動きません
PC
Windows ／ MacノートPCでも可。カクつく場合は「軽量モード」で
NETWORK
必要3D描画・顔認識ライブラリの読み込みと、音声認識に使います
CAMERA
任意顔で照準・手でメニュー操作・AR背景・俯瞰モードに使用
CONTROLLER
任意：Wiiリモコン（MotionPlus推奨）・ヌンチャクBluetoothでペアリングして使います
MIC
任意起動ワード用。なくても Enter キーで起動できます
02

はじめかた

  1. Chrome か Edge でタイトル画面を開くトップの「PLAY」から。最初に「SYSTEM STANDBY」と出たら、画面をクリックします。
  2. マイクの使用を許可するブラウザに聞かれたら「許可」。起動ワードの聞き取りに使います。
  3. （任意）Wiiリモコンをつなぐ先にPCとBluetoothでペアリングしておき、右下の「🎮 Wiiリモコン接続」から選びます。一度つなげば、次からは自動で認識されます。
  4. Ⓐを押しながら「ハロー・ニューワールド」リンク演出が始まります。そのあとジョブを選ぶと、練習モードへ。
  5. 練習モードを終えたら、ボス戦へHOMEボタン（キーボードは M）でメニュー →「⚔ 本番へ」。

MEMO　ゲームを開いた直後は、一度クリックかキーを押すまで音が鳴りません。ブラウザの仕様で、Wiiリモコンのボタンだけでは音を出す許可にならないためです。

03

タイトル画面では、Ⓐを押している間だけマイクが音声を聞き取ります。「ハロー・ニューワールド」と認識されるとリンク開始。多少の聞き間違い（「ハロー ニュー ワールド」「Hello New World」など）は通るようにしてあります。

05

入力とモード

どれも組み合わせ自由です。手元にあるものから足していってください。

MOUSE & KEY

マウス＆キーボード

いちばん手軽な標準操作。カメラなしでも最後まで遊べます。

FACE TRACKING

顔トラッキング

Webカメラで顔の向きを読み、視点と照準を動かします。感度・中心位置を調整可能。

HAND GESTURE

ハンドジェスチャー

ピースサインでメニューを開き、指先でカーソル操作。リモコンを置かずに設定を変えられます。

WII REMOTE

Wiiリモコン＋ヌンチャク

MotionPlusのジャイロでソードスキル、ヌンチャクで二刀流。当たると振動します。

THIRD PERSON

俯瞰モード（VRM）

VRMアバターを読み込み、全身の動きを反映。体を左右に動かして回避します。カメラは1台（バック）を使います。

AR VIEW

AR背景

2台目のカメラ映像、または手持ちの動画・画像をボスの背景に。タイトル画面でも「📷 AR背景」で切り替えられます。

06

設定のコツ

重いときは「軽量モード」

カメラ設定の「負荷モード」で切り替えます（初期設定は軽量）。描画解像度を下げ、顔認識は1秒に20回、手の認識は5回に間引き、背景カメラを640×360で取り込みます。

カメラが逆になる

内蔵カメラはフロント（顔・手の認識）、USBカメラはバック（背景）に自動で割り当てます。逆になったら「⇄ 入れ替え」で。

ソードスキルが出にくい

メニューの「⚔ ソードスキル」で判定のしきい値を変えられます。いちばん簡単なのは、出したい動きを1回だけやって、直後に「①縦重撃を登録」などのボタン（キー 1〜4）を押す方法。直前の振りを基準に自動で調整されます。

横斬りの左右が逆に判定される

「横斬りの左右を反転」をONにしてください。リモコンの持ち方によって起こることがあります。

07

困ったとき

Q.01音が鳴らない
ゲームを開いてから一度、画面をクリックするかキーを押してください。ブラウザは、ユーザーが操作するまで音を出さない仕組みになっています。メニューの効果音・BGMの音量も確認を。
Q.02「ハロー・ニューワールド」に反応しない
  • Chrome か Edge で開いているか
  • マイクの使用を「許可」したか（アドレスバー左の鍵マークから変更できます）
  • ネットにつながっているか（音声認識はオンラインで動きます）
  • Ⓐ（または Space）を押したまま話しているか
どうしても反応しないときは Enter で声なしで起動できます。
Q.03Wiiリモコンがつながらない
先にOSのBluetooth設定でペアリングしてから、ゲーム内の「Wiiリモコン接続」を押してください。一覧に出ない場合はリモコンの1+2ボタンを押して接続待ちにします。MotionPlusが見つからないときは加速度だけの操作になり、ソードスキルは使えません。
Q.04カメラが映らない・顔を認識しない
他のアプリ（ビデオ会議など）がカメラを使っていると開けません。顔認識は明るい場所のほうが安定します。中心がずれたら C でリセット。
Q.05ファイルを直接開くとうまく動かない
PCに保存したファイルをダブルクリックで開くと、マイクやカメラが制限されることがあります。GitHub Pagesなどで公開したURLから開くか、フォルダで python -m http.server を実行して localhost から開いてください。
